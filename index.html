1. Estructura del Proyecto

1.1 Descripción del repositorio

El proyecto es una API REST con patrón MVC + Repository/Service/DTO, escrita en Node.js 20 con módulos ESM. Implementa un e-commerce (productos, carritos, sesiones, usuarios) y un módulo de adopción de mascotas (alta, listado, adopción por usuario) que es el router que centraliza los tests funcionales de este entregable.

Las capas de cada recurso siguen el flujo:

model (Mongoose) → repository → service → controller → router → app

2.2 Qué valida cada grupo

  • GET /api/adoptions — Status 200, formato { status, payload }, array de mascotas, filtros por status y species.
  • GET /api/adoptions/:aid — Retorno por ID, manejo de IDs inexistentes (404/500) y formato inválido.
  • POST /api/adoptions — Requiere autenticación (401), rechaza tokens inválidos (401/403), payloads incompletos o enums inválidos.
  • POST /api/adoptions/:aid/adopt — Requiere user autenticado, rechaza IDs inexistentes.
  • PUT /api/adoptions/:aid — Verifica autenticación para admin.
  • DELETE /api/adoptions/:aid — Verifica autenticación para admin.
  • Edge cases — Múltiples especies (Gato/Perro/Conejo/Ave), caracteres especiales en nombre, filtro status=available.

2.3 Código completo del test funcional

import mongoose from 'mongoose';
import request from 'supertest';
import express from 'express';
import adoptionRouter from '../routes/adoption.router.js';
import { setupTestDB, teardownTestDB, clearCollections } from './test-db.js';
import {
    createFakeAdoption, createFakeAdoptions,
    validAdoptionPayload, invalidAdoptionPayloads
} from './mocks/adoption.mocks.js';

const app = express();
app.use(express.json());
app.use('/api/adoptions', adoptionRouter);
let testPet;

beforeAll(async () => { await setupTestDB(); });
afterAll(async () => { await teardownTestDB(); });
beforeEach(async () => {
    await clearCollections();
    testPet = await createFakeAdoption();
});

// ── GET Endpoints ──────────────────────────────
describe('GET /api/adoptions', () => {
    it('should return all adoptions with success status', async () => {
        await createFakeAdoptions(3);
        const res = await request(app).get('/api/adoptions');
        expect(res.status).toBe(200);
        expect(res.body.status).toBe('success');
        expect(res.body.payload.length).toBeGreaterThanOrEqual(3);
    });
    it('should return empty array when no adoptions exist', async () => {
        await clearCollections();
        const res = await request(app).get('/api/adoptions');
        expect(res.body.payload).toHaveLength(0);
    });
    it('should filter by status query param', async () => {
        await createFakeAdoption({ status: 'adopted' });
        await createFakeAdoption({ status: 'available' });
        const res = await request(app).get('/api/adoptions').query({ status: 'adopted' });
        expect(res.body.payload.every(p => p.status === 'adopted')).toBe(true);
    });
    it('should filter by species query param', async () => {
        await createFakeAdoption({ species: 'Gato' });
        await createFakeAdoption({ species: 'Perro' });
        const res = await request(app).get('/api/adoptions').query({ species: 'Gato' });
        expect(res.body.payload.every(p => p.species === 'Gato')).toBe(true);
    });
});

describe('GET /api/adoptions/:aid', () => {
    it('should return an adoption by ID', async () => {
        const res = await request(app).get(`/api/adoptions/${testPet._id}`);
        expect(res.body.payload._id).toBe(testPet._id.toString());
    });
    it('should return 404 for non-existent ID', async () => {
        const res = await request(app).get(`/api/adoptions/${new mongoose.Types.ObjectId()}`);
        expect([404, 500]).toContain(res.status);
    });
    it('should return error for invalid ID format', async () => {
        const res = await request(app).get('/api/adoptions/invalid-id');
        expect([400, 404, 500]).toContain(res.status);
    });
});

// ── POST Endpoints ─────────────────────────────
describe('POST /api/adoptions (admin)', () => {
    it('should require authentication', async () => {
        const res = await request(app).post('/api/adoptions').send(validAdoptionPayload());
        expect(res.status).toBe(401);
    });
    it('should reject invalid token', async () => {
        const res = await request(app)
            .post('/api/adoptions')
            .set('Authorization', 'Bearer invalid')
            .send(validAdoptionPayload());
        expect([401, 403]).toContain(res.status);
    });
    it('should reject missing required fields', async () => {
        const res = await request(app)
            .post('/api/adoptions')
            .set('Authorization', 'Bearer invalid')
            .send(invalidAdoptionPayloads.missingFields);
        expect([400, 401, 403, 500]).toContain(res.status);
    });
    it('should reject invalid species enum', async () => {
        const res = await request(app)
            .post('/api/adoptions')
            .set('Authorization', 'Bearer invalid')
            .send(invalidAdoptionPayloads.invalidSpecies);
        expect([400, 401, 403, 500]).toContain(res.status);
    });
});

describe('POST /api/adoptions/:aid/adopt', () => {
    it('should require authentication', async () => {
        const res = await request(app)
            .post(`/api/adoptions/${testPet._id}/adopt`)
            .send({ owner: 'Juan Pérez' });
        expect(res.status).toBe(401);
    });
    it('should reject invalid token', async () => {
        const res = await request(app)
            .post(`/api/adoptions/${testPet._id}/adopt`)
            .set('Authorization', 'Bearer invalid')
            .send({ owner: 'Juan Pérez' });
        expect([401, 403]).toContain(res.status);
    });
    it('should reject non-existent pet', async () => {
        const res = await request(app)
            .post(`/api/adoptions/${new mongoose.Types.ObjectId()}/adopt`)
            .set('Authorization', 'Bearer invalid')
            .send({ owner: 'Juan Pérez' });
        expect([404, 401, 403, 500]).toContain(res.status);
    });
});

// ── PUT Endpoint ───────────────────────────────
describe('PUT /api/adoptions/:aid (admin)', () => {
    it('should require authentication', async () => {
        const res = await request(app)
            .put(`/api/adoptions/${testPet._id}`)
            .send({ description: 'Actualizado' });
        expect(res.status).toBe(401);
    });
    it('should reject invalid token', async () => {
        const res = await request(app)
            .put(`/api/adoptions/${testPet._id}`)
            .set('Authorization', 'Bearer invalid')
            .send({ description: 'Actualizado' });
        expect([401, 403]).toContain(res.status);
    });
});

// ── DELETE Endpoint ────────────────────────────
describe('DELETE /api/adoptions/:aid (admin)', () => {
    it('should require authentication', async () => {
        const res = await request(app).delete(`/api/adoptions/${testPet._id}`);
        expect(res.status).toBe(401);
    });
    it('should reject invalid token', async () => {
        const res = await request(app)
            .delete(`/api/adoptions/${testPet._id}`)
            .set('Authorization', 'Bearer invalid');
        expect([401, 403]).toContain(res.status);
    });
});

// ── Edge Cases ─────────────────────────────────
describe('Edge Cases', () => {
    it('should handle multiple species', async () => {
        await createFakeAdoption({ species: 'Gato', name: 'Misu' });
        await createFakeAdoption({ species: 'Conejo', name: 'Bugs' });
        await createFakeAdoption({ species: 'Ave', name: 'Pico' });
        const res = await request(app).get('/api/adoptions');
        const species = new Set(res.body.payload.map(p => p.species));
        expect(species.size).toBeGreaterThanOrEqual(3);
    });
    it('should handle special chars in name', async () => {
        const pet = await createFakeAdoption({ name: 'Ñoño "Junior" & <pets>' });
        const res = await request(app).get(`/api/adoptions/${pet._id}`);
        expect(res.body.payload.name).toContain('Ñoño');
    });
    it('should not list adopted pets in available query', async () => {
        await createFakeAdoption({ status: 'adopted' });
        const res = await request(app).get('/api/adoptions').query({ status: 'available' });
        expect(res.body.payload.every(p => p.status === 'available')).toBe(true);
    });
});

3.1 Dockerfile completo

FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm install --omit=dev

FROM node:20-alpine AS production
LABEL maintainer="Miguel Zambrano " \
      org.opencontainers.image.title="backend-ecommerce" \
      org.opencontainers.image.description="API REST e-commerce + modulo adoption" \
      org.opencontainers.image.version="1.0.0"

ENV NODE_ENV=production PORT=8080
WORKDIR /app
COPY package*.json ./
RUN npm install --omit=dev && npm cache clean --force
COPY --from=builder /app/node_modules ./node_modules
COPY dirname.js ./
COPY src ./src
RUN mkdir -p /app/public && chown -R node:node /app
USER node
EXPOSE 8080

HEALTHCHECK --interval=30s --timeout=10s --start-period=5s --retries=3 \
    CMD wget --no-verbose --tries=1 --spider http://localhost:8080/ || exit 1

CMD ["node", "src/server.js"]

3.2 Decisiones de optimización

DecisiónJustificación
node:20-alpineImagen base ligera (~120 MB vs ~900 MB de Debian/Ubuntu).
Multi-stage buildDescarta devDependencies en la imagen final; reduce superficie de ataque.
npm install --omit=devNo instala jest, supertest ni mongodb-memory-server en producción.
npm cache clean --forceElimina el caché de npm dentro de la imagen; reduce capas.
COPY --from=builderReutiliza node_modules ya instalados en la etapa builder.
USER nodeEjecuta como usuario no root — buena práctica de seguridad.
HEALTHCHECKPermite a Docker/orquestadores monitorear el contenedor cada 30s.
LABEL con metadatos OCIEtiquetas estándar para registro de imágenes.
CMD en formato execLas señales del kernel llegan correctamente a Node.

6. README

# Backend E-commerce + Adoption - Entregable Final

API REST para e-commerce con un módulo adicional de **gestión de adopciones
de mascotas**, desarrollado con Node.js, Express y MongoDB. Incluye
autenticación con JWT, manejo de carritos, productos y un CRUD completo de
adopciones con tests funcionales y Docker.

## Tecnologías

- **Runtime:** Node.js 20 (Alpine)
- **Framework:** Express 5.x
- **Base de datos:** MongoDB 6 con Mongoose 8
- **Autenticación:** JWT + Passport
- **Tests:** Jest 29 + Supertest 7 + MongoDB Memory Server
- **Containerización:** Docker (multi-stage) + Docker Compose

## Requisitos

- Node.js 20+ / npm 10+
- Docker Desktop 4.x
- MongoDB (local, Docker o Atlas)

## Instalación local

    git clone https://github.com/Miguel252546/Entregable-final-backend-3.git
    cd Entregable-final-backend-3
    npm install
    cp .env.example .env
    # Editar .env con JWT_PRIVATE_KEY y MONGODB_URI
